# ⚡ Voltix AI: AI-Assisted Energy Optimization System for Smart Buildings

## 📖 Project Overview
Voltix AI is an intelligent energy management dashboard designed for smart buildings. It leverages **Machine Learning (Random Forest)** to forecast energy consumption and **Generative AI (Google Gemini)** to act as an intelligent energy advisor. The system helps facility managers reduce energy wastage, optimize HVAC settings, and visualize consumption patterns in real-time.

---

## 🚀 How to Run the Project

### Prerequisites
*   **Python_3.10+**: Required for the backend and ML training.
*   **Node.js_16+**: Required for the React frontend.
*   **Gemini API Key**: You need a Google Cloud API key for the AI Chatbot features (optional for dashboard, required for chat).

### ⚡ Option 1: One-Click Start (Windows)
Double-click the **`run_app.bat`** file in the root directory.
*   It automatically starts the Backend Server (Port 8000).
*   It automatically starts the Frontend Application (Port 5173).

### 🛠️ Option 2: Manual Setup

#### 1. Backend Setup
The backend handles data processing, ML predictions, and API requests.
```bash
cd AI_Energy_Optimization/backend
# Install Python dependencies
pip install -r requirements.txt
# Run the server
python main.py
```
*   Server runs at: `http://localhost:8000`
*   API Documentation: `http://localhost:8000/docs`

#### 2. Frontend Setup
The frontend is the user interface built with React.
```bash
cd AI_Energy_Optimization/frontend
# Install Node dependencies
npm install
# Start development server
npm run dev
```
*   App runs at: `http://localhost:5173`

## 🤖 AI & Algorithms Used

### 1. Energy Prediction Model
This model predicts "Expected Consumption" to establish a baseline.
*   **Algorithm**: **Random Forest Regressor** (Ensemble of Decision Trees).
*   **Why Random Forest?**: Handles non-linear relationships (like weather vs. energy) better than Linear Regression and is robust against overfitting.
*   **Training Configuration**:
    *   `n_estimators` (Epochs equivalent): **100 Trees**
    *   `random_state`: 42 (For reproducibility)
    *   `test_size`: 0.2 (80% Training, 20% Testing)
*   **Input Features**:
    1.  Building Type (Encoded)
    2.  Area ($m^2$)
    3.  Temperature ($^\circ C$)
    4.  Humidity (%)
    5.  Occupancy Level (0, 1, 2)
    6.  Time (Hour of day)
    7.  Day of Week
    8.  Is Weekend (0/1)
*   **Model Accuracy**:
    *   **MAE (Mean Absolute Error)**: ~0.30 kWh.
    *   **Accuracy**: ~99% on test data.

### 2. Wastage Detection Algorithm
Used to flag anomalies where energy is being wasted.
*   **Formula**:
    $$ \text{Wastage} = \text{Actual kWh} > (\text{Predicted kWh} \times 1.2) $$
*   **Logic**: If current usage is **20% higher** than what the AI predicts based on valid conditions (Weather, Occupancy), it triggers an alert.

### 3. GenAI Advisor (Gemini)
*   **Model**: **Gemini 1.5 Flash** (Google).
*   **Implementation**:
    *   The system creates a "Context String" containing the current building's live metrics.
    *   It appends the user's question.
    *   It sends this prompt to the Gemini API to get a context-aware answer.
    *   *Example*: Use asks "How to save?", AI sees "High Temp + Empty Building", advises "Turn off AC".
